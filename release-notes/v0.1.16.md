# v0.1.16

## Harness Alpha.4 support

- Targets DeepSeek Harness 0.1.2-alpha.4 with exact runtime peer pins.
- Replaces the removed Alpha.2 continuable setup registry with Alpha.4's
  agent/created and agent.ctx lifecycle bridge.
- Sends member follow-up messages through subagents.sendMessage() and keeps
  the old followup() API as a compatibility fallback.
- Detects unsupported hosts without blocking Harness startup and emits a clear
  compatibility warning.
- Ships the generated lib/index.js and lib/client.js package entrypoints.
